# Bag of Gleps · design system (v3 "sketchbook")

The live look, shipped 2026-10-20 (PR #3). `index.html` and `beta/online-lobby.html` hold the actual CSS; this page is the reference for anyone changing it.

## Type (Google Fonts)
- **Pirata One**: the "Bag of Gleps" logo and card backs only
- **Anton**: headings and buttons, uppercase
- **IBM Plex Sans**: body text, 16px or more so other players can read it
- **IBM Plex Mono**: small labels, eyebrows, meta lines
- **Permanent Marker**: rare hand-written scrawls

## Shapes
Square corners, 2px inked borders, hard black offset shadows (`12px 12px 0 #000`), dashed outlines for "taped" boxes. No rounded or pastel elements.

## Copy
Short and dry. Home hero: "Draw it. Play it." Game page: "The table is ~~locked~~ open."
